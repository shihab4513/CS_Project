# All-in-One Colab Bundle

The generated `ai_package_detection_ALL_IN_ONE_COLAB.zip` contains the project
code plus final evidence reports for `requests-2.32.3` and `lodash-4.17.21`.

In Google Colab, upload only that ZIP. Then open and run
`notebooks/RUN_ALL_IN_ONE_LLM_COLAB.ipynb`. The notebook downloads both local
LLM review outputs as one `final_llm_reviews.zip` file.

The LLM reads only evidence JSON already included in the bundle. It does not
execute package code and its review is assistance, not a ground-truth label.
